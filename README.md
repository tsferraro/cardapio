# Cardápio da Família

App da família para planejar o cardápio da semana, publicado no GitHub Pages.

Este repositório é **público** e guarda só código, catálogo de ingredientes e dado fictício para teste. O plano da nutricionista, as receitas de terceiros, os preços pagos e o estado da família ficam numa planilha Google de acesso restrito, lida por uma API em Apps Script que só responde a dois e-mails liberados.

- `teste/` · página de teste do login Google no iPhone (onda 2a, P5)
